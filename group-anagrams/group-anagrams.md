# 例题:字母异位词分组

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

字母异位词是由重新排列源单词的所有字母得到的一个新单词。

示例 1:
> 输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]<br>
> 输出: [["bat"],["nat","tan"],["ate","eat","tea"]]<br>
> 解释：<br>
> 在 strs 中没有字符串可以通过重新排列来形成 "bat"。<br>
> 字符串 "nat" 和 "tan" 是字母异位词，因为它们可以重新排列以形成彼此。<br>
> 字符串 "ate" ，"eat" 和 "tea" 是字母异位词，因为它们可以重新排列以形成彼此。

示例 2:
> 输入: strs = [""]<br>
> 输出: [[""]]

示例 3:
> 输入: strs = ["a"]<br>
> 输出: [["a"]]

提示：
- 1 <= strs.length <= 10⁴
- 0 <= strs[i].length <= 100
- strs[i] 仅包含小写字母

---

核心观察：异位词排序后得到相同 **签名 (sig)**。用 hash(sig) 把候选放进同一桶，桶内再用 `strcmp(sig)` 确认是否真同组（hash 只加速，不能代替精确比较）。

# 思路1: 先建表，再按桶分组

对应 `source1.c`。

**节点含义**：每个 hash 节点 = **一个原串**（挂 `str` + `sig` + `used`）。

**步骤**：

1. 遍历所有串，对每个串算 `sig`（排序），`key = hash(sig)`，头插入对应桶。  
   注意：必须按 **签名** 算 key，不能按原串；否则异位词可能进不同桶。
2. 建完表后，扫每个桶：
   - 用 `anchor` 沿链表走；若 `anchor->used` 则跳过（已被某组收走）
   - 否则以 `anchor->sig` 开一组：再扫一遍桶，把所有 `!used && sig 相同` 的串收进同一 col，并标 `used`
   - 同桶但签名不同的串（真碰撞）不会进这一组；等轮到它们当 `anchor` 时再各自成组

```
桶内示例（hash 碰撞）:  eat → bat → tea
  anchor=eat: 收 eat/tea (sig=aet)，标 used
  anchor=bat: 未 used → 单独成组
  anchor=tea: 已 used → skip
```

**要点**：`!used` 只表示「还没被收」；是否同组还要看 `strcmp(sig)`。碰撞的不同串不会丢，也不会被误并成一组。

**复杂度**：签名约 O(n · k log k)；分组阶段桶内最坏接近 O(B² · k)。空间 O(n · k)（存签名）。

# 思路2: 建表时就分组

对应 `source2.c`。

**节点含义**：每个 hash 节点 = **一个异位词组**（挂 `sig` + `strs[]` 列表），不再是单个串。

**步骤**：

1. 对每个串算 `sig`，`key = hash(sig)`。
2. 在桶的链上找有没有 `strcmp(node->sig, sig) == 0` 的节点：
   - 找到 → 把原串 append 到该节点的 `strs[]`（旧 sig 可 free）
   - 找不到 → 新建节点挂上该 `sig`，再 append
3. 全部插入后，扫一遍表，把各节点的 `strs` 导出为返回结果即可（这一步不再 `strcmp`）。

```
插入 "eat" → 新组 [eat] (sig=aet)
插入 "tea" → 同桶 strcmp 命中 → [eat, tea]
插入 "bat" → 同桶但 sig 不同 → 新组 [bat]
```

**和思路1的差别**：链更短（节点数 = 组数 G ≤ n，而不是串数 n），比较通常发生在插入时的短链上；没有「先堆满再二次聚类」的阶段。

**复杂度**：签名同样约 O(n · k log k)；查找组平均接近 O(1) 次 `strcmp`（桶均匀时）。空间 O(n · k)。

# 对比

| | 思路1 | 思路2 |
|--|--|--|
| 节点 | 一个串 | 一个组 |
| 分组时机 | 建完表再扫桶 | 插入时完成 |
| 碰撞处理 | `used` + `strcmp` | 插入时 `strcmp` 找组 |
| 实现 | 两阶段，好想 | 一遍插入，通常更省比较 |
